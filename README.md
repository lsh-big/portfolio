## 주요 기능

- 아이보리·딥그린 색상과 화면 크기에 맞춰 배치가 바뀌는 반응형 디자인
- 프로젝트 소개 펼치기와 실제 서비스 새 탭 열기
- 현재 위치를 표시하는 메뉴, 스크롤 진행 표시, 맨 위로 이동
- 키보드 탐색, 본문 바로가기, 모션 줄이기 설정 지원
- 이메일 주소 복사 및 이름·제목·이메일·전화번호·메시지 문의 양식
- 별도 이력서 페이지와 인쇄용 레이아웃

문의 양식은 이름·제목·메시지와 이메일 또는 전화번호 중 하나를 입력하면 메일 앱을 엽니다. **메일 앱에서 내용을 확인한 뒤 직접 전송하는 방식**이며, 서버로 문의를 저장하거나 자동 발송하지 않습니다.

이력서의 **인쇄 / PDF 저장** 버튼을 누른 뒤 브라우저 인쇄 창에서 PDF로 저장할 수 있습니다. 이력서에는 개인정보가 포함되어 있으며 검색 제외 설정을 적용했습니다. 로그인이나 접근 제한 기능은 없습니다.

## 로컬 실행

프로젝트 폴더에서 다음 명령을 실행합니다. Python이 설치되어 있어야 합니다.

```sh
python -m http.server 8000 --bind 127.0.0.1
```

브라우저에서 [포트폴리오](http://127.0.0.1:8000/) 또는 [이력서](http://127.0.0.1:8000/resume.html)를 엽니다. 서버는 터미널에서 `Ctrl + C`로 종료합니다.

## 수정 및 배포

1. 해당 HTML·CSS·JavaScript 파일을 수정하고 로컬에서 확인합니다.
2. 변경 내용을 GitHub 저장소에 커밋하고 푸시합니다.
3. GitHub Pages 배포가 완료되면 [공개 사이트](https://lsh-big.github.io/portfolio/)에서 확인합니다.

이전 디자인이 보이면 `Ctrl + F5`로 새로고침합니다. 교육 상태와 프로젝트 주소가 변경되면 홈페이지·이력서·README의 관련 내용도 함께 갱신합니다.
